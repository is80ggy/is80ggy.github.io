## Introduction

Bogdan Doroftei ("we," "our," or "us") built the **URADMonitorReader** app as an open/client utility application for viewing uRADMonitor sensor data. This SERVICE is provided by us at no cost and is intended for use as-is.

This page is used to inform visitors regarding our policies with the collection, use, and disclosure of Personal Information if anyone decided to use our Service.

---

## Information Collection and Use

For a better experience while using our Service, **URADMonitorReader does not collect, store, or share any personal user data on external servers controlled by us.**

- **No Personal Data Collection:** We do not collect names, email addresses, phone numbers, precise location data, or device identifiers.
- **No Analytics or Tracking:** We do not use third-party analytics tools, crash reporting tools that collect identifiable user data, or tracking SDKs.
- **No Advertising:** The app does not display advertisements, nor does it share data with advertising networks.

---

## Local Data Storage

**URADMonitorReader** stores necessary authentication credentials (such as your uRADMonitor API key or credentials) locally on your device using Android's secure encrypted storage (`EncryptedSharedPreferences`).
- These credentials remain strictly on your device.
- They are used solely for authenticating your requests directly with the official uRADMonitor API (`uradmonitor.com`).
- You can clear these credentials at any time by clearing app data or logging out within the application.

---

## Third-Party Services & API Interactions

**URADMonitorReader** acts as a client interface that communicates with the official uRADMonitor backend services (`uradmonitor.com`) to fetch device readings, historical statistics, and sensor telemetry.

- **Data Transmission:** When you use the app, network requests are sent directly to the official uRADMonitor API endpoints over secure HTTPS connections.
- **Third-Party Privacy Practices:** Please note that uRADMonitor endpoints and servers are operated by uRADMonitor / MagForce SRL (or respective owners). **We are not in control of how third-party uRADMonitor servers process, log, or handle incoming API requests, interactions, or IP addresses.** We encourage you to review the official [uRADMonitor Privacy Policy](https://www.uradmonitor.com) for details on their data handling practices.

---

## Permissions

The app requests the following system permission:
- **`android.permission.INTERNET`**: Required strictly to communicate with the official uRADMonitor API to retrieve your device sensor readings.
